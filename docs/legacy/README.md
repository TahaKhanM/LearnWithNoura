# Historical product evidence

The repository and local directory retain the legacy Seneca name. The historical ADR and archived audit screenshots are preserved without rewriting their evidence. They do not define the active product identity; current UI, prompts, metadata, runtime documentation and deployment configuration use Noura.

The one-window storage migration intentionally recognizes `SENECA_DATA_DIR` and `seneca.db`. These names exist only to migrate and retain user data safely.
