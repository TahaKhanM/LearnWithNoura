# Retained evaluation images

These 53 PNG/JPEG files are the original synthetic diagrams and browser screenshots referenced by the checked-in September 2026 M2, M3 and M7 evidence verifiers. They were added to version control when this project was prepared for public release so a fresh checkout can verify the retained hashes. The images have not been regenerated or edited to improve historic results.

The learner names, lesson text and marks shown here belong to synthetic test journeys, not real children. The contact sheets show the 39 bounded curriculum fixtures. Their existence establishes a retained example, not general pedagogical quality or real-user efficacy. Original report status and rejected runs remain unchanged.

Other generated artifacts remain ignored. Do not add recordings, session dumps, credentials or real learner data. Some browser tests write a new image to a historical path; do not replace a tracked evidence image with that recapture.
